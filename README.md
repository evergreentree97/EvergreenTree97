### AI와 함께 일하는 방식

Claude Code와 Codex, 역할별 에이전트를 업무 전반에 활용합니다.
저장소 구조와 코드 규칙, 완료 조건은 프로젝트 지침으로 관리하고,
반복 절차는 Agent Skill과 개발 도구로 만들어 재사용합니다.
업무에서 사용하던 한국어 문체 교정 규칙도 [K-Humanizer](https://github.com/evergreentree97/K-Humanizer)라는 Agent Skill로 정리해 공개했습니다.

AI가 만든 결과는 작업 유형에 따라 검증합니다.

| 대상 | 검증 |
|---|---|
| 코드 | 리뷰와 자동 테스트 |
| Android 기능 | 별도 테스트 빌드와 실제 기기 확인 |
| 모델 | 자동 평가와 실제 휴먼 리뷰 |
